# Tic Tac Toe 🎮

A classic 2-player Tic Tac Toe game built from scratch using **HTML, CSS, and 
JavaScript** — no frameworks or libraries required.

## Features
- Clean, responsive 3x3 grid UI
- Turn-based play for Player X and Player O
- Automatic win and draw detection with a highlighted winning line
- Live scoreboard that tracks wins and draws
- One-click restart

## Live Demo
🔗 [Play it here](https://preetham-adithya.github.io/Tic-Tac-Toe/)

## Built With
- HTML5
- CSS3 (Grid layout)
- Vanilla JavaScript (DOM manipulation, no dependencies)

## How to Run Locally
Clone the repo and open `index.html` in any browser — that's it, no installation needed.
